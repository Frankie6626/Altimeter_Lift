# Lift Altimeter

## Summary

Meet Lift: the smallest, affordable, open-source altimeter for model rockets. Get useful data without compromising safety. Features include reverse polarity protection, low power shut off, highly power efficient, a 320g accelerometer, and a barometer. A tuned Extended Kalman filter ensures clean, robust data, making Lift a feature-rich choice.
